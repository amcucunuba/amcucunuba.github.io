📣Project: Marketing Campaign Analysis with A/B Testing & Random Forest

Overview

This project analyzes the effectiveness of a bank's telemarketing campaign. It includes:

A/B testing on call duration vs subscription conversion

A machine learning model (Random Forest) to predict customer subscription likelihood

Feature importance analysis to guide campaign strategies

🤖 Predictive Modeling
Built a Random Forest model to predict customer response.

Accuracy: 85%

Recall (yes): 82%

The model performs well for identifying customers likely to convert.

🔍 Key Features Driving Conversions
Top 5 features (from feature importance):

- Duration of the call

- Previous successful contact

- Balance

- Day of month

- Customer's age 

![Feature Importance](feature_importance.png)

🧪 A/B Test Goal
Determine whether longer phone calls result in a higher conversion rate (subscription to a term deposit).

Result:
✅ Statistically significant difference found — longer calls improved conversion rate by ~6.2%.


📊 Business Recommendations
Prioritize longer calls and refine scripting for longer engagement.

Retarget customers with prior success history.

Target campaigns to months with higher conversion trends.

Consider A/B testing call strategies by job or marital status for deeper optimization.
